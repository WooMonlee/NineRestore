## 3. 必须先过的真机四项（【缺条件】，不能用模拟顶替）

RC2 的 4 项真机确认，**一项都不能跳**：

1. **BIOS 下不再出现问号**
   BIOS 机器进救援界面，确认屏幕没有 `?` / 白底方块；日志出现 `FONT: ... rc=7`。
2. **UEFI 下 C 在 D 之前并被默认推荐**
   GPT 与 MBR 各跑一次，确认分区列表按**物理起始偏移**排序，C 显示在 D 之前，
   推荐行是系统盘。
3. **还原完成后再进菜单只出一句人话并自动回 Windows**
   完整还原成功后，重启再进 `NineRestore`，确认没有 1/2/3 三选一，
   只显示一句提示，然后自动重启回 Windows。
4. **固件菜单里只剩一条 `NineRestore`**
   升级机器（旧条目名可能是 `SysRecover`）安装菜单后，确认 UEFI 启动项 / BCD 项 /
   GRUB 标题都只有一条 `NineRestore`，没有旧名残留。

补充真机项（若无条件，至少记录"未测"）：

- 目标为正在运行的系统盘 → 暂存 → 重启 → 还原 → 自动回新系统，全链路走通；
- 中断场景：swap 中途断电后，首屏出现三选一，不会自动回滚；
- `keep` 模式 + 清空不完整 → 中止在 `wipe-incomplete`，目标盘未写；
- 装过菜单的 BIOS 机器：还原后菜单消失 → 下次运行程序自动恢复。
